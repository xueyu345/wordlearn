# 学习通 · STUDY HUB

小学生的英语单词 + 数学错题本。两门功课，一个入口。

纯前端、零依赖、可离线安装。双击 `index.html` 就能玩（首次需联网或先跑一次本地服务器把词库缓存下来）。

> 项目原名「单词小勇士 / WORD HERO」。改名后仓库名 `wordlearn` 与已发布链接保持不变，本地学习记录也不受影响。

## 怎么用

```bash
# 方式一：起一个本地服务器（推荐，PWA / 离线缓存 / 图片上传需要 http 协议）
一定要在文件夹里运行~
python -m http.server 8000
# 然后打开 http://localhost:8000

# 方式二：直接双击 index.html
# 浏览器会拦下 file:// 下的 fetch，页面会退回上一次缓存的词库；
# 如果从未加载过，会显示提示页。数学错题本不受影响。
```

在手机/平板上用 Chrome 或 Safari 打开后，可以通过「添加到主屏幕」当成 App 使用，断网也能继续学。

## 界面布局

打开后是「左侧导航 + 右侧内容」的两栏结构，手机、平板、电脑三端同一份代码：

| 屏幕 | 侧栏形态 |
| --- | --- |
| 电脑（≥1024px） | 260px 常驻，一直看得见 |
| 平板（768–1023px） | 84px 图标条；点顶栏 ☰ 展开成完整侧栏 |
| 手机（<768px） | 默认收起；点顶栏 ☰ 从左侧滑出，点遮罩或 ✕ 收回 |

左侧栏里依次是：**学习仪表盘、英语、数学、错题试卷**，然后是**当前年级**（一到六年级下拉框），最下面是**账户**和**设置**。

右侧内容区跟着左边的选择走：

- 点**英语** → 英语单词主页（学一学 / 选一选 / 拼一拼 / 连一连）
- 点**数学** → 数学错题本主页（记错题 / 解题挑战 / 抽题复习 / 错题组卷）
- 点**错题试卷** → 把数学错题 + 英语错词汇总成一张卷子（也可以从两个错题本里点「组卷」直接带条件进来）
- 点**账户**、**设置** → 对应的页面
- **什么都没点时（默认首屏）→ 显示学习仪表盘**，仪表盘顶部还有英语、数学、AI 讲题老师三张快捷入口卡

进到「学一学」「拼一拼」这类二级页面时，左侧对应的科目仍然高亮，不会丢失位置感。

## 年级与教材

年级下拉框在**左侧栏**，英语教材、数学教材两个下拉框在**顶栏**。切换任何一个 = 切换一整套学习档案。

### 年级

- **内容按年级隔离**——每个年级只看得到自己那一档的英语主题和数学知识点
- **记录各自独立**——星星、连续打卡、已学单词、错词本、数学错题都分年级保存，兄弟姐妹共用一台设备也互不干扰
- 当前年级记在 `studyHubGrade.v1`，下次打开自动回到上次选的年级

### 教材版本（可选）

| 学科 | 可选版本 | 覆盖年级 | 说明 |
| --- | --- | --- | --- |
| 英语 | 全国通用版 | 1–6 | 按主题分类的常用词，不绑定具体教材 |
| 英语 | 人教 PEP · 三年级起点 | 3–6 | 人民教育出版社《英语(PEP)》，单元名沿用课本 `Unit 1 Hello!` 等 |
| 英语 | 外研版 · 三年级起点 | 3–6 | 外语教学与研究出版社《英语》(新标准)，按 `Module` 组织 |

| 数学 | 北师大版 | 1–6 | 单元名与北师大课本目录一致（生活中的数、混合运算、比的认识……） |

## 两块内容

### 英语 · 单词关卡

| 玩法 | 说明 | 星星 |
| --- | --- | --- |
| 学一学 | 3D 翻转单词卡，正面词形+音标+发音，背面释义+例句 | 首次认识 +1 ⭐/词 |
| 选一选 | 10 题四选一，英文→中文 / 中文→英文 / 听音选词三种形态轮换，3 颗心 | 每答对 +1 ⭐ |
| 拼一拼 | 听发音拼写，字母遮罩 + 逐字母提示 + 2 次容错 | 拼对 +2 ⭐ |
| 连一连 | 6 组 12 张翻牌配对，计时按步数评级 | 最多 +6 ⭐ |

另有**混合大挑战**（全部单词随机抽题）和**错词本**（连续答对 2 次自动移出，可单独发起错词挑战）。

### 数学 · 错题本

- **记错题**：手写题目，或拍照/截图贴图（最多 3 张，自动压缩到长边 1100px、JPEG 质量 0.72）。支持**直接粘贴截图**。
- **必填项**：题目 + 正确答案 + 知识点。可选填「我的答案」「题型」「错在哪里」。
- **知识点**：随所选**数学教材 + 年级**变化。通用版按知识板块分，北师大版 / 人教版按课本单元名分（三年级北师大版就是「混合运算、观察物体、加与减、乘与除、周长、乘法、年、月、日、认识小数」）。也支持自行新建。
- **错题列表**：按知识点筛选、关键词搜索（题目/知识点/错因/答案）、按「全部 / 待攻克 / 已掌握」过滤。可标记掌握、编辑、删除。
- **抽题复习**：按知识点抽题（也支持全部知识点），每轮最多 10 道，未掌握的优先、错得多的靠前。
  流程是「先自己做一遍 → 看答案 → 这次做对了吗」，答对标记为已掌握并 +1 ⭐，答错则 `wrongCount + 1` 并退回待攻克，下一轮优先出现。

数学错题存在 `localStorage` 的 `studyHubMath.v1.gN`（N 为年级）里，**只在你自己的设备上**，不会上传任何服务器。

## 词库怎么改

词库的唯一真源是 `words.js` 和分年级的 `words-grade-*.js`，改完运行一次构建脚本：

```bash
node tools/build-words-json.js
```

它会校验字段完整性、单元 id 唯一性、`grade` 合法性和 `book` 是否在 `books-en.js` 里，并生成 `words.json`，同时按「教材 × 年级」打印主题数与词数。页面运行时只读取 `words.json`，**不会**加载这些 `.js` 源文件。

`words.js` 用 spread 把各版本、各年级的词库拼在一起：

```js
units: [
  ...window.GRADE_12_UNITS,   // words-grade-12.js：通用版 一 + 二年级
  { book: "general", grade: 3, id: "animals", /* ... */ },  // 通用版三年级直接写在这里
  ...window.GRADE_456_UNITS,  // words-grade-456.js：通用版 四 + 五 + 六年级
  ...window.PEP_UNITS,        // words-pep.js：人教 PEP 三起
  ...window.FLTRP_UNITS       // words-fltrp.js：外研版 三起
]
```

一个单词的字段：

```js
{ w: "cat", ipa: "/kæt/", zh: "猫", emoji: "🐱", en: "A cat likes fish.", cn: "猫喜欢鱼。" }
```

新增一个主题，就往 `units` 数组里加一项（`book` + `grade` 都必填）：

```js
{
  book: "general",        // general / pep / fltrp，必须已在 books-en.js 中声明
  grade: 4,               // 1–6，且该版本必须覆盖这个年级
  id: "clothes",          // 全局唯一，会拼进 URL 和存储 key，别改
  name: "衣服穿搭", en: "Clothes", emoji: "👕",
  color: "#7057F5", soft: "#F0ECFF",   // 主题色 / 浅色背景
  desc: "今天穿什么？",
  words: [ /* ... */ ]
}
```

教材版本本身（名称、覆盖年级、单元大纲）写在 `books-en.js` 的 `EN_BOOKS` 里；数学教材的知识点表写在 `index.html` 的 `MATH_BOOKS` 常量里（`kps` 按年级分）。

`goal` 字段控制每日目标单词数（默认 10）。

> 注意：单词的 `id` 由「主题 id + 数组下标」生成（如 `animals-0`）。在已有主题中间插入单词会让后面单词的 id 整体后移，导致学习记录错位。加词请追加到数组末尾，或新建主题。

## 登录与云同步

顶栏右侧的 **登录** 按钮可以开通云端同步，支持四种登录方式：

- **邮箱**：注册 = 邮箱 + 密码 + 邮箱验证码（先点「获取验证码」验证邮箱，再设置密码）；登录 = 邮箱 + 密码；忘记密码可发重置邮件
- **手机号**：注册 = 手机号 + 密码 + 短信验证码；登录 = 手机号 + 密码（暂不支持手机号自助重置密码）
- **微信登录**：点「微信登录」整页跳转授权，回调后自动换登录态。需满足两个条件：① 在云服务管理页打开「微信登录」开关；② 在正式域名下使用（本地预览跳不过去）
- **WorkBuddy 登录**：同上，用 WorkBuddy 账号一键登录
- **同步内容**：英语进度（星星、连续打卡、已学单词、错词本）和数学错题，覆盖全部「年级 × 教材」档案
- **自动同步**：本机一有变化，2.5 秒后自动上传；换设备用任一方式登录同一账号，会把云端与本机进度**双向合并**（两边都不白学——单词取并集、星星取大值、同一道错题任一边攻克即算攻克）
- **数据隔离**：云端每行数据由数据库 RLS 强制只属于登录者本人；一台设备退出登录时本机档案会清空，不会串给下一个登录的人
- **离线可用**：未登录、断网时一切照旧，进度先存本机，登录后自动补同步

后端为 WorkBuddy 内置云服务（数据库 `study_progress` 表，含 `owner_id` 行级安全）；云服务不可用时顶栏显示「仅本机」，学习功能不受影响。微信 / WorkBuddy 登录的开关要在云服务管理页的 Provider 卡片里手动打开，并且只在发布后的正式域名上生效。

## 声音开关

顶栏有两个独立开关：

- 🔊 **音效**——按键、翻卡、答对答错的提示音（WebAudio 合成）
- 🔈 **语音朗读**——单词和例句的英文朗读（浏览器 TTS）

英语首页底部还有**自动朗读**开关：关掉后翻卡、出题时不再自动发声，需要时点小喇叭才读，适合安静环境。

## 设置

顶栏 ⚙️ 进入 `#/settings`，分四块：

- **学习偏好**：每日单词目标（5/10/15/20）、每轮题目数量（5/10/15，选一选 / 拼一拼 / 连一连 / 抽题复习共用）、音效、语音朗读、自动朗读、拼写是否区分大小写。偏好存在当前「年级 + 教材」档案里，随云同步走
- **账号与同步**：登录状态一目了然，可发起立即同步、退出登录；未登录时给出去登录的入口
- **数据与备份**：导出全部档案为 JSON 备份文件、从文件导入恢复（覆盖前需确认）、清空本机数据（双重确认）。导出文件不含错题图片（图片以 dataURL 存在档案里，包含在备份内；体积大时建议定期重新导出）
- **关于**：版本号、离线缓存状态、当前档案、检查更新、更新日志与隐私说明

## 数学解题挑战

数学错题本首页点「🧩 先做再记」进入 `#/math/solve`，把「做题 → 对答案 → 收错题」串成一条线：

- **按年级出题**：题库按当前「年级 + 教材」现场生成，一年级只会出 20 以内加减和认识钟表，六年级才出现分数乘除、百分数、圆柱圆锥，绝不超纲
- **三种玩法**：指定知识点专练、按当前年级混合练，每轮 5/10/15 道
- **做完即判**：每题写完点「检查」马上知道对错；不会可以看提示或跳过
- **解析跟着课本走**：每道题都配该年级课本讲法的分步解题思路和易错提醒（比如二年级减法讲「想加算减」，五年级方程讲等式的性质）
- **答错自动收进错题本**：结算页把做错和跳过的题列出来（可勾选），一键收进错题本——题目、正确答案、我写的答案、解析步骤一起带走；之前记过的只累加错误次数，不会重复
- **复习时能看解析**：从挑战里收进的题，在「抽题复习」里会显示完整解题步骤
- **答案判定很宽容**：1/2 和 0.5、全角数字、带单位（如「18 厘米」）都能判对
- 录入错题时「正确答案」也改成了可选——还没对答案的题可以先记下来，之后在编辑里补

## 错题试卷

数学错题本首页点「📝 错题组卷」、英语错词本点「📝 错词组卷」，或者左侧栏直接点「错题试卷」，进 `#/paper`。把两个错题本里攒的东西一次性汇总成一张卷子。

- **两本合一张卷**：数学错题 + 英语错词可以各出各的，也能合成一份，题量、取题范围（待攻克 / 全部 / 已掌握）、知识点、英语题型（中译英 / 英译中 / 混合）都能调
- **选题有轻重**：数学按「未掌握优先 + 错得多的靠前」排，英语按错词次数排，永远是最该练的先进卷
- **在线作答判分**：卷面上直接写答案，点「✅ 交卷判分」立刻出对错和正确率
  - 数学走题库的宽松判定：1/2 和 0.5、全角数字、带单位（「22 厘米」）都算对
  - 英语大小写不敏感，中文释义写了好几种说法时命中任意一种就算对
  - 当时没记正确答案的题不参与判分，不会被误判成错
- **成绩回写错题本**：数学答对标记「已掌握」、答错累加错误次数；英语走 `markWord`，连续答对两次自动移出错词本
- **也能打印出来用笔写**：点「🖨️ 打印 / 存 PDF」走浏览器打印，顶栏侧栏和所有按钮都不上纸，只留干净的 A4 卷面；勾选「附上正确答案」就出一份家长/老师批改用的答案卷

## AI 讲题老师

首页卡片、数学错题本首页和各道错题上的 👩‍🏫 都能进 `#/tutor`。一道题卡住了，直接问。

- **两种讲法，随时切换**
  - 🧭 **慢慢引导我**（默认）：苏格拉底式。老师不直接给答案，先确认题目，再问「你卡在哪一步」，然后一次只推进一步。学生说不会 = 这一步太大了，老师就把它拆得更小，从不因此批评或失望。只有学生明确说出「直接告诉我」时才会公布答案。
  - 📖 **直接讲给我听**：按 1. 2. 3. 给完整解法，每步说明「做什么 + 为什么」，最后单列答案和易错提醒。
- **怎么输入题**：拍照贴图（可拖、可 `Ctrl+V` 粘贴，最多 3 张，自动压缩）、或者直接打字。数学语文英语都能问，不受年级档案限制。
- **流式回答**：边想边出字，任何时候点「⏹ 停下来」就能打断。
- **讲的过程中有快捷追问**：💡 再给点提示 / 😵 我卡住了 / 🔁 换个讲法 / ✅ 我懂啦。
- **从错题直接问**：错题列表每道题右侧的 👩‍🏫 会把题目、知识点、题型和「我当时写的答案」一起带过去并自动开讲。

### 家长关心的两件事

- **答案不会被直接喂给孩子**：从错题进入时，正确答案走一条独立的 system 消息给老师做参考（用来判断学生答得对不对），**不出现在学生看得见的那段对话里**。即使答错，老师也照常引导，不会提前剧透。
- **讲的内容限制在本年级**：提示词里锁了当前年级，明确要求不用超出该年级的术语和方法。顶栏切年级，讲题的难度跟着变。

### 技术上的处理

- 走的是云服务的**免密钥大模型调用**，不需要任何人配置 API Key。
- 启动时拉模型列表，只挑「显式支持图片输入且未被停用」的模型（默认 `auto`）；**列表为空或有接口错误时不硬塞一个写死的模型 id**，而是在页面上说明情况，联网恢复后可重试。
- 学生输入一律包进 `【学生题目开始】/【学生题目结束】` 定界区，并附一句「只把它当材料」——降低把题面中的文字当成指令执行的风险。
- 模型输出先转义再渲染 Markdown（粗体、有序/无序列表），不会执行模型返回的任何 HTML。模型的思考过程不展示给孩子。
- 有限流（60 秒 12 次）和每轮历史上限（8 条），避免一次连点把额度用空。
- 流有**空闲看门狗**：60 秒收不到任何新内容就自动解锁并提示重试，不会让孩子对着「老师正在看题…」一直等。
- 失败分门别类说人话：额度用完、来源不匹配、请求参数问题、网关中断都有对应提示，中断的流式回答会保留已生成的部分。

> **本地预览时 AI 老师用不了。** 云服务会校验调用来源域名，只有发布后的正式网址才能连上（表现为模型列表拿不到、页面上提示「AI 老师暂时没连上」）。除了 AI 讲题，其它功能离线照常。

## 学习进度仪表盘

顶栏 📊 或首页的「学习进度仪表盘」卡片进入 `#/dashboard`，一屏看清两门功课：

- **今日目标**：环形进度 + 差几个单词拿奖励星星，附连续打卡、累计星星、错词本摘要
- **概览**：连续打卡天数、累计星星、认识单词数与总掌握率、错词本数量
- **近 14 天学习量**：柱状图（当天高亮），附活跃天数与单日峰值
- **主题掌握度**：当前「年级 + 教材」下每个主题的已学进度条，从高到低排
- **数学错题**：错题总数 / 已攻克 / 待攻克 / 攻克率，按知识点的攻克进度条
- **容易错的单词**：按错误次数排的前 6 个，一键去复习错词
- **打卡成就**：8 枚徽章（连续打卡、词汇量、星星数、攻克错题、错词清零），达标自动点亮

## 技术说明

- 原生 HTML/CSS/JS，无框架、无构建；唯一外链是云服务 SDK（CDN `<script>`，暴露全局 `WorkBuddyCloud`）
- **登录与云同步**（可选用）：
  - WorkBuddy 云服务：邮箱 / 手机号验证码注册 + 密码登录，微信 / WorkBuddy OAuth 一键登录，数据表 `study_progress`（`owner_id TEXT DEFAULT auth.uid()` + RLS）
  - 云端键 `scope.grade.book`（如 `math.3.general`），英语/数学、各年级、各教材互不覆盖
  - 本地保存与云端上传解耦：本地永远先落盘，云端失败只影响同步指示灯
- **按「年级 + 教材」隔离存储**：
  - 英语进度 `wordHeroState.v1.gN`（通用版）/ `wordHeroState.v1.<book>.gN`（其他版本）
  - 数学错题 `studyHubMath.v1.gN` / `studyHubMath.v1.<book>.gN`
  - 当前年级 `studyHubGrade.v1`，英语教材 `studyHubEnBook.v1`，数学教材 `studyHubMathBook.v1`
  - 旧版的 `wordHeroState.v1` / `studyHubMath.v1` 会在首次启动时自动迁移到三年级 + 通用版档案
- 词库离线副本存 `wordHeroWordsCache.v1`（存全年级数据，体积不大）
- 手写 hash 路由；带查询串的路由会先剥掉 `?` 再切分路径
- Service Worker 策略：页面与词库网络优先（保证更新及时），静态资源缓存优先
- 所有插入 DOM 的用户内容都经过 `esc()` 转义
- 已处理 `prefers-reduced-motion`、键盘操作（空格翻卡、1–4 选项、回车提交、Esc 退出）

## 发版：版本要改哪些地方

版本号没有自动同步机制，发布新版时按这张清单过一遍（当前 `v1.6.0`，缓存号 `v13`）：

| # | 文件 | 位置 | 说明 |
| --- | --- | --- | --- |
| 1 | `index.html` | `const APP_VERSION = "..."` | **网页版真源**，设置页「关于」读它 |
| 2 | `index.html` | 「关于 → 更新日志」的 `<ul class="settings-log">` | 补一条新版本说明 |
| 3 | `sw.js` | `const VERSION = "vN"` | 离线缓存号，**必须跟着加一**，否则老缓存不失效、用户拿不到新页面 |
| 4 | `desktop/package.json` | `version` | Electron 打包版本，安装包 / 便携版文件名由它插值 `desktop/README.md` 里的产物名也要一起改 |
| 5 | `miniprogram/utils/store.js` | `APP_VERSION` | 小程序「我的」页显示的版本 |
| 6 | `miniprogram/package.json` | `version` | 小程序包版本（`package-lock.json` 里还有两处，一并同步） |

改完网页还要同步两份副本：

```bash
node desktop/tools/copy-web.js        # 网页 → desktop/app/（等价于 cd desktop && npm run sync）
node miniprogram/tools/build-data.js  # 只有词库变了才需要：words.json → utils/words-data.js
```

`desktop/app/` 和小程序里的页面逻辑都是**副本不是源码**，改功能请改根目录的 `index.html`，再同步过去。

## 已知限制

- 结算页依赖内存中的 `lastResult`，刷新 `#/result` 会回到首页
- 词库 id 基于数组下标，中间插入单词会导致历史记录错位（见上文）
- **AI 讲题老师只在发布后的正式网址上可用**：云服务会校验调用来源，本地预览 `http://localhost` 连不上模型。其余功能离线照常
- AI 讲题的额度属于应用作者，页面做了限流（60 秒 12 次），但如果被大量陌生人访问仍可能触达配额上限
- 浏览器 TTS 的音色取决于系统，不同设备效果会有差异
- 数学错题的图片以 dataURL 存在 `localStorage`，单设备约 5MB 上限**（各年级共用这一配额）**；图片已压缩，但错题特别多时可能写满，建议定期清理已掌握的题
- 数学错题图片只存本机不进云端（云端只同步文本数据），换设备后旧图片不会跟过去
- 云服务的邮箱验证码 / 短信验证码依赖邮件 / 短信服务，个别邮箱或号码可能收得慢（邮箱记得看垃圾箱）
- 微信 / WorkBuddy 登录要在云服务管理页打开开关，且只在发布后的正式域名上可用；本地预览会提示「正式域名下使用」
- 手机号登录暂不支持自助重置密码（忘记密码请走邮箱渠道）
- 跨年级的旧链接（如一年级的 `#/unit/animals`）会被导回该科目的首页，不会静默显示错误内容
